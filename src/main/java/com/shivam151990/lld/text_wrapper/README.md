A text wrap library is a utility or library that helps format text by wrapping it to fit within a specified width. This is particularly useful when displaying text in environments with limited horizontal space, such as consoles, terminals, or UI components.

Common Features of Text Wrap Libraries
* Word Wrapping: Breaks text into lines at word boundaries to avoid splitting words.
* Custom Width: Allows specifying the maximum line width.
* Indentation: Supports adding indentation (spaces or tabs) to wrapped lines.
* Hyphenation: Optionally adds hyphens when breaking words.
* Handling Long Words: Can handle long words that exceed the specified width by breaking them or truncating them.
* Platform Independence: Works across different platforms and environments.
